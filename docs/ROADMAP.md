# Roadmap de 3 meses

> El calendario se expresa por semanas porque la fecha exacta de entrega no está definida en este documento. El compromiso es una ventana total de **3 meses**.

## Objetivo del calendario

El último mes no debe utilizarse para rescatar sistemas fundamentales. Para entonces el core loop debe existir.

## Mes 1 — Fundaciones

### Semanas 1–2
- Crear proyecto Godot
- Configurar Git/GitHub
- Estructura de carpetas
- Player
- Movimiento
- Cámara
- Colisiones
- Mapa inicial
- Interacción básica

### Semanas 3–4
- NPCs
- Diálogo básico
- TimeManager
- UI inicial
- Recursos de juego
- Primer prototipo académico
- Primera tarea

### Milestone M1

**Vertical slice técnico básico:**

El jugador puede moverse por el campus, interactuar, avanzar tiempo y ejecutar al menos una actividad académica.

## Mes 2 — Core gameplay

### Semanas 5–6
- Sistema completo de materias
- Tareas
- Exámenes
- Calificaciones
- Energía
- Estrés
- Dinero

### Semanas 7–8
- Transporte
- Eventos
- Trámite administrativo
- Quests
- Consecuencias
- Guardado/carga
- Flujo completo del cuatrimestre

### Milestone M2 — CRÍTICO

El cuatrimestre debe poder jugarse de inicio a fin, aunque falten arte, audio y balance final.

**A partir de aquí, cualquier feature nueva requiere justificación explícita.**

## Mes 3 — Contenido y polish

### Semanas 9–10
- Contenido de las 3 materias
- NPCs finales
- Diálogos
- Eventos
- Finales
- Balance

### Semanas 11–12
- UI polish
- Audio
- Animaciones
- Corrección de bugs
- Optimización básica
- Playtesting
- Build final
- Documentación de entrega

### Milestone M3 — ENTREGA

Build jugable y estable con:

- core loop completo
- contenido MVP
- guardado
- finales
- documentación
- bugs críticos resueltos

## Regla de riesgo

Si M2 se retrasa, recortar contenido antes de retrasar la entrega.

Orden de recorte:

1. eventos secundarios
2. variantes narrativas
3. cantidad de NPCs
4. cantidad de tareas
5. finales adicionales

No recortar primero:

- movimiento
- tiempo
- académico
- tareas/exámenes
- recursos
- guardado
- flujo de inicio a final
